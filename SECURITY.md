# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Entropia team takes security issues seriously. If you discover a security vulnerability within this repository, please do NOT file a public issue.

Instead, please send an email to:
**ooluwadamilare356@gmail.com**

Please provide:
- A clear description of the potential vulnerability
- Steps to reproduce or proof-of-concept code
- The potential impact of the vulnerability

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve the issue promptly before public disclosure.
